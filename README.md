# Contact Manager (C Standard)

A simple, lightweight command-line contact management system written in **Standard C**. This project was developed after completing **Week 3 of Harvard's CS50**, focusing on data structures and algorithmic logic.

## 🚀 Features
- **Custom Data Structures**: Utilizes `struct` to organize contact information (names and phone numbers).
- **Sorting Algorithm**: Implements **Bubble Sort** to automatically organize contacts in alphabetical order.
- **Search Functionality**: Includes a **Linear Search** feature to retrieve contact details by name.
- **Pure C**: Developed without the `cs50.h` library to practice standard C memory and string management.

## 🛠️ How It Works
The program follows a clear three-step logic:
1. **Input**: Prompts the user to enter a set number of contacts.
2. **Processing**: Sorts the entire list using the `strcmp` function for alphabetical comparison.
3. **Interaction**: Displays the sorted list and allows the user to query specific contacts.
